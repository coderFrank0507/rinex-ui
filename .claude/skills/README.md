## 🎯 技能详细说明

### 1. 组件生成技能 (`rinex-component.md`)

**功能概述：**
自动根据用户需求生成符合 Rinex UI 规范的 React 组件。

**适用场景：**
- 快速创建新的 UI 组件
- 保持组件代码的一致性
- 减少重复的样板代码编写
- 确保遵循项目最佳实践

**核心功能：**
- ✅ 自动生成组件文件结构
- ✅ 创建 TypeScript 类型定义
- ✅ 生成样式变体配置
- ✅ 添加性能优化
- ✅ 支持可访问性

**使用示例：**
```
用户: "帮我创建一个按钮组件，需要有 primary、secondary 和 outline 三种样式"
Claude: [自动生成完整的 Button 组件代码]
```

### 2. 代码审查技能 (`rinex-review.md`)

**功能概述：**
对现有代码进行多维度审查，提供改进建议和优化方案。

**适用场景：**
- 代码质量保证
- 性能优化建议
- 可访问性检查
- TypeScript 类型安全审查
- 项目规范符合性检查

**审查维度：**
- 🔍 **类型安全** - TypeScript 规范和最佳实践
- ⚡ **性能优化** - React 性能优化建议
- ♿ **可访问性** - ARIA 属性和键盘导航
- 🎨 **代码规范** - 项目代码风格和规范
- 🏗️ **架构设计** - React 最佳实践

**审查结果：**
- 📊 综合评分报告
- ⚠️ 问题分类和严重程度
- 💡 具体改进建议
- 🔧 代码修复示例

### 3. Skill 开发指南 (`skill.md`)

**功能概述：**
提供 Skill 开发的完整指南和最佳实践。

**适用场景：**
- 开发新的 Claude Code 技能
- 了解 Skill 的工作原理
- 学习技能开发最佳实践
- 技能维护和更新

**核心内容：**
- 📖 Skill 开发规范
- 🛠️ 实现技巧和模板
- 📋 评估和改进方法
- 🤝 团队协作指南

## 🔧 技能配置和使用

### 技能激活

Skills 会自动在 Claude Code 中生效，无需额外配置。

### 使用方式

1. **直接对话** - 在对话中描述需求，Claude 会自动匹配相关技能
2. **明确指定** - 明确告诉 Claude 使用特定技能
3. **上下文触发** - 基于对话上下文自动触发

### 示例对话

```
用户: "帮我创建一个输入框组件"
Claude: [触发 rinex-component 技能]

用户: "审查一下这段代码的性能问题"
Claude: [触发 rinex-review 技能]

用户: "如何为这个项目开发一个新的技能？"
Claude: [参考 skill.md 提供指导]
```
