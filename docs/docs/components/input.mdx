# Input 输入框

---

### 代码演示

#### 基础

```tsx preview
import { Input } from 'rinex-ui';

export default function App() {
  return (
    <div>
      <Input placeholder="请输入" />
    </div>
  );
}
```

#### 禁用状态

通过 disabled 属性指定是否禁用 input 组件

```tsx preview
import { Input } from 'rinex-ui';

export default function App() {
  return (
    <div>
      <Input disabled placeholder="请输入" />
    </div>
  );
}
```

#### 前后插槽

通过`InputGroup`组件配合`Prefix`和`Suffix`组件指定前后缀

```tsx preview
import { InputGroup } from 'rinex-ui';
import { User, Search } from 'lucide-react';

export default function App() {
  return (
    <>
      <InputGroup>
        <InputGroup.Prefix className="px-2">
          http://
        </InputGroup.Prefix>
        <InputGroup.Input placeholder="请输入" />
        <InputGroup.Suffix>
          <Search size={16} />
        </InputGroup.Suffix>
      </InputGroup>
    </>
  );
}
```
